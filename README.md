# arbitrage-aware-option-surface-model-risk
Research notebooks for arbitrage-aware SPY option-surface construction, SVI/SSVI repair, Heston/Bates calibration, and model-risk synthesis.
This repository is provided as a research notebook archive for review, audit, and methodological reference. It is not packaged as a clone-and-run application. The notebooks use local project paths and may require path edits, dependency installation, and replacement data sources before rerunning.
